About Me

Building Security Programs That Actually Reduce Risk

I've spent more than 20 years building enterprise security programs that hold up under audit, scale across global systems, and actually reduce risk — not just document it. At Avaya, I've led the transformation of the entire SAP security and access governance function, redesigning thousands of roles using a least-privilege model, cutting SOX violations by 35%, and building automation that slashed user provisioning turnaround by up to 90%.

My work spans SAP GRC Access Control 10.1 and 12.0, S/4HANA and ECC security architecture, Segregation of Duties (SoD) governance, SOX audit ownership, Identity and Access Management (IAM), and non-SAP platforms including Microsoft Dynamics 365 and Azure cloud environments. I lead teams, own audit relationships, and build tools that make security operations measurably better.
